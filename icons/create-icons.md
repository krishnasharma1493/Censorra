# Extension Icons

You need to create the following icon files for the extension:

- `icon16.png` (16x16 pixels) - Used in the extension management page
- `icon48.png` (48x48 pixels) - Used in the extension management page  
- `icon128.png` (128x128 pixels) - Used during installation and in the Chrome Web Store

## Quick way to create icons:

1. Use any image editor (Photoshop, GIMP, Canva, etc.)
2. Create a simple design with:
   - Shield or block symbol 🛡️
   - Colors that match the extension theme (purple/blue gradient)
   - Clear, simple design that works at small sizes

3. Or use online icon generators:
   - https://favicon.io/
   - https://www.canva.com/
   - https://icons8.com/

## Temporary solution:
You can also temporarily use placeholder images or copy existing icons from other extensions for testing purposes.
